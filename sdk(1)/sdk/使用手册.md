视频编辑SDK在充分发挥平台软硬件能力的基础上，提供了丰富的API接口，集成了常见的视频编辑能力。使得集成该SDK的应用开发者得以方便、快捷地在自己的应用程序中实现诸如视频拼接、裁剪、字幕、画布、变速、转码、背景音乐、特效、滤镜、美颜、字体等视频处理功能，为用户提供便捷、流畅、有趣的音视频内容再创作功能。

#### 一、主要概念

| 类名 | 简介 |
| --- | --- |
| VideoFactory | 视频编辑引擎，负责视频编辑工程中的预览，导出，seek等操作。 |
| Clip | Clip 是视频编辑中的基本单位，包括VideoClip, AudioClip, ImageClip. 所有的Clip添加到项目中会被按前后顺序渲染输出。 |
| VideoProject | 用来管理所有需要被编辑处理后输出的 各种clip、背景音乐，文字、主题模板、 视频图层。 |
| Overlay | 对应某个时间点上，需要同时编辑、渲染、输出的各种对象，如多画面显示以及字幕。 |
| VideoFactoryListener | SDK的使用者需要注册到VideoFactory，用以监听和接受VideoFactory 的notify, 需要使用者重写实现。 |
| VideoRenderView | 视频预览窗口，有VideoEditorView (TextureView类型)和VideoSurfaceView(SurfaceView类型)两个类型继承实现，可以通过activity xml加入到Activity中。 |

##### 图像到画布的裁切设定和背景填充

导入的视频图像和最终导出的画布的宽高比例可能会不同，者就需要设定图像在画布上的裁切模式，有三种选着方式

package com.vivo.videoeditorsdk.layer;
public enum CropMode {
    Fill,        // 平铺拉伸，宽高比例会发生变化，会导致图像变形
    Stretch,    // 等比拉伸放大，宽高比例不变，图像放大会使得图像显示不全
    Fit,        // 等比缩小，宽高比例不变，图像可能只占显示区域一部分
}

通过clip的函数设定裁切模式

videoClip.setCropMode(CropMode.Fit);

如果选择CropMode.Fit 模式，图像就可能会无法覆盖整个画布，用下面方法设定对于画布无图像覆盖的区域的着色方式。

//BackgroundModeNone = 0; //表示无背景, 默认黑色

该功能会把一个视频文件的画面处理成倒序的视频流，翻转后不会保存音频数据。

设置全局对象

import com.vivo.videoeditorsdk.videoreverse.VideoReverser; VideoReverser mVideoReverser; String mSourceFile = "/storage/Movies/reverse_source_fiel.ts"; String mOutputFile = "/storage/Movies/reverse_output_file.mp4"; //该功能需要一个文件位置存放临时数据。 String mTempDataDir = ”/storage/VideoEditor";

启动翻转器

mVideoReverser = new VideoReverser(); mVideoReverser.setDataSource(mSourceFile); mVideoReverser.setTargetFile(mOutputFile); mVideoReverser.setTempPath(mTempDataDir); mVideoReverser.setReverseListener(new VideoReverser.ReverseListener() {     //收到消息后，具体的操作要放在另外一个thread里面做。     @Override     public void onStart() {         //已经开始，开始更新UI进度。     }      @Override     public void onProgressChange(int percent) {         //更新翻转进度。     }      @Override     public void onError(int code) {         //发生错误，需要释放VideoReverser     }      @Override     public void onComplete() {         //成果结束，需要释放VideoReverser     } });  mVideoReverser.start();

翻转完成，失败，或主动结束后，需要释放VideoReverser

mVideoReverser.release(); mVideoReverser = null;
