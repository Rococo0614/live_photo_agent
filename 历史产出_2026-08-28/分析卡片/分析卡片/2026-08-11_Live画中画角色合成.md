# Live画中画角色合成 · 会动的安洁

## 一句话玩法
在静态 Live 照片上，用「画中画」叠加一个会动的游戏角色素材，并用**正片叠底混合模式消掉素材白底**，得到「静态场景 + 动态角色」的会动照片。

## 一、玩法机制拆解
| 组件 | 观察证据 | 说明 |
|---|---|---|
| 静态背景 Live | 背景天空/云层/前景绿色条状物全程静止，无位移无变形 | 底层是普通静态/微动 live 照片 |
| 动态角色素材 | 卡通角色（安洁莉娜骑扫帚）向右匀速平移约30px，双马尾微飘 | 角色来自官方 gif/live 素材，自带平移动画 |
| 画中画叠加 | 角色位于前景遮挡物上方、背景云层下方，与背景无接触 | 美图秀秀「拼贴→画中画」实现图层叠加 |
| 正片叠底去白底 | 角色边缘有 1-2px 白色描边，整体与背景分离 | 素材是白底，用「混合模式-正片叠底」把白底滤掉 |
| 主体动镜头不动 | 角色平移而前景条状物/背景不动 → 是主体移动非镜头移动 | 角色动画独立于静态背景 |

## 三、技术痕迹观察
- **高置信度**：画中画图层叠加（角色悬浮于背景之上、与背景无接触、前景条状物在角色之前的空间关系明确）；正片叠底去白底（角色边缘 1-2px 白描边是正片叠底对非纯白区域的典型残留，且整体与背景分离）。
- **中/低置信度**：前景绿色条状物模糊是否为「后期叠加的景深/前景遮挡」存疑，也可能是原图自带；角色平移是 gif 动画而非拍摄运动（角色无透视变化、背景静止），置信度中高。
- 用户肉眼判断优先：从教程步骤看，这确实是「画中画 + 正片叠底」的标准流程，观察与教程一致。

## 四、涉及的原子能力（客观描述）
- 多图层合成（画中画/图层叠加）
- 混合模式运算（正片叠底：白底滤除，需逐像素做乘法混合）
- 动态素材导入与播放（gif/live 作为可动图层）
- 静态照片 + 动态图层的时间轴同步
- 素材库（官方角色 gif/live）
- 当前由美图秀秀第三方 App 实现；手机系统相机/相册原生通常只支持静态拼贴，不支持「动态素材叠加 + 混合模式」这一组合。

## 五、产品化可能性分析
**当前痛点**：用户要跨 App（美图秀秀）+ 手动多步（导入gif→导出live→画中画→正片叠底），且必须理解「正片叠底」这种专业混合模式概念，门槛在"懂混合模式"而非"想合成"。

**产品化方向**：把「角色素材叠加到实拍 live」做成系统级一键能力：
- 相册/相机内置「动态贴纸」入口，选一个会动的角色/贴纸，拖到 live 照片上即可
- 系统自动做**自动去底**（AI 抠图/自动白底滤除），用户不需要懂正片叠底

**技术路径**：AI 智能抠像（角色分离）+ 动态贴纸素材库 + live 时间轴合成 + 一键导出。原子能力串联：感知（识别角色/场景）→ 编辑（抠图/混合）→ 输出（live）。

**降门槛效果**：从「跨App 5步 + 懂混合模式」→「相册里点选角色 + 拖放 = 完成」，交互简化为 2 步。

**vivo 可行性**：中。技术上 AI 抠像和动态贴纸都是成熟能力（端侧可做），难点在素材版权（游戏角色素材授权）和「动态贴纸库」的供给。建议分期：一期做「静态贴纸叠加 + 自动去底」验证需求，二期接动态素材。
